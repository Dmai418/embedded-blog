# C语言基础

## 变量与数据类型

```c
int a = 10;           // 整型
float b = 3.14;       // 浮点型
char c = 'A';         // 字符型
unsigned int d = 20;  // 无符号整型
```

## 指针（嵌入式重中之重）

```c
int a = 10;
int *p = &a;  // p 指向 a 的地址
*p = 20;      // 通过指针修改 a 的值
```

## 位运算（寄存器操作必备）

```c
// 置位某一位
GPIOA->ODR |= (1 << 5);    // PA5 输出高电平

// 清零某一位
GPIOA->ODR &= ~(1 << 5);   // PA5 输出低电平

// 检查某一位
if (GPIOA->IDR & (1 << 5)) // 读取 PA5 电平
```

## static / volatile / const

| 关键字 | 作用 | 嵌入式场景 |
|--------|------|-----------|
| static | 限制作用域/保持值 | 局部变量保持状态 |
| volatile | 禁止编译器优化 | 寄存器变量、中断变量 |
| const | 只读 | 表格、字符串 |
